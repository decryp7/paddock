| [0041](0041-deterministic-timing-in-tests.md) | Deterministic timing in tests (proposed rule 60): tests control time through injected seams (`Clock`, a new `Pace`, named `Seams` in `paddock_jobs::time`; `wait_until`, `HangGuard`, `ScriptedChild` in `paddock-testkit`; `useTestClock`, `untilState`, `frozenClock` for specs), check C71 over every test file with a ratchet baseline (replaces C30), and a nightly starved run that slows the tests, not the machine (cgroup quota, job-object cap, `PRIO_DARWIN_BG`; bounded burners only as a fallback) (accepted 2026-11-03 by the user, after review rounds 1-2) |
| [0042](0042-one-owner-per-harness-and-small-batches.md) | One owner per shared harness and smaller merge batches (proposed rule 61): the register `docs/harnesses.toml` (paths, one home branch, a lease, `home` or `additive` mode), check C72 (harness changes come from the home; stale homes), batch caps (60 commits, 200 files, 72 hours) with check C73 and a `Batch-size-waived:` trailer, release lines land in untagged parts, shared parts first, a `commit-msg` hook instead of landing copies, CI once per tree (accepted 2026-11-03 by the user, after review rounds 1-2) |
| [0043](0043-dialogs-size-to-content.md) | Dialogs size to their content (WPF `SizeToContent`): a size mode per kind (Manual, Height), one measure loop in the page with a last-sent baseline, epoch and seq, all sizing on the main thread at the OS edge (`GetDpiForWindow`, `AdjustWindowRectExForDpi`, `DWMWA_EXTENDED_FRAME_BOUNDS`, `WM_GETDPISCALEDSIZE`, a refit posted after `WM_DPICHANGED`), only a real resize switches to Manual; checks over every dialog kind and at 100/150 % and a DPI change on Windows; ships in Dyno 1.1.0 (accepted 2026-11-03) |
| [0044](0044-widget-grid-free-size-and-arrangement.md) | Widget grid (accepted 2026-11-03): free size and drag-and-drop arrangement on a snapped grid of columns by 24 px rows; placements are rectangles with per-kind size rules, swap, push-down and gravity computed by `paddock-widgets` (previews in the app's own process through its `tauri` feature), derived narrower arrangements, an upgrade from span layouts, an "Edit layout" mode with pointer and keyboard move and resize, the engine's per-widget `moves`, the 1.0 value kept under its old key until the first edit; Dyno 1.1 first |
| [0049](0049-small-merges-behind-switches-and-wire-notes.md) | Small merges behind feature switches (proposed rule 65): declared switches injected into `compose` (default off, a removal tag or date, debug-only override, the UI reads them through the backend, the mock defaults to the shipped table, C79), lines land their parts (25 commits, 48 hours), a per-app release freeze enforced at landing (D7 accepted), `./dev drift` and C81 (amends ADR 0042 §3), each wire versioned from its postcard-schema schema and golden encodings against the last tag with notes for the reader (C80), `merge=union` for the ADR indexes, lessons and benchmark logs but not the changelogs (C82), and a no-build push check on every branch push (rule 50 (f) proposed) (accepted 2026-11-04: user decisions D1–D7, independent review 3 rounds) |
| [0056](0056-service-repair-one-declared-state-machine.md) | Service repair as one declared state machine (proposed, ER-21): one persisted state (`Idle`, `Attempting{Replacing, Awaiting}`, `Held`, `Removing`, format 2 with a one-way migration) written before each OS step, one pure `transition(record, event, observation, caps)` that start, first run, switch, resume, repair and uninstall all go through, separate signals (service, job, the app's own agent), an OS file lock released on death, and an exhaustive model test over a simulated OS with a crash at every call (amends the service chapters of Dyno ADR 0010; red on c612dbfa6) |
| [0076](0076-owned-background-work.md) | Owned background work (accepted 2026-11-09 by the user, D1–D10 as recommended, D7 = c; rule 74; ER-21): every thread, task and child process has one owner (`TaskGroup` in `paddock_jobs::tasks`, `paddock_proc::Supervised`, `thread::scope`) whose stop signals and waits within a bound and reports; drop hands off to one reaper per clock without blocking (latches, hooks and child kills on the reaper, children ended inline if it cannot start, no self-join, `stop_async` in tokio); call contexts get a `Weak`-backed `PeerRef`; detached work only through four registered kinds with caps; builds ADR 0024's C42 as a syn pass with a register and a ratchet (new raw spawns fail at once; tags blocked by entries that hold a descriptor, folder, connection or child); a per-owner leak guard in `paddock-testkit` and nextest `leak-timeout` as fail; composes with ADR 0072; survey of 442 shipped spawn sites (162 joined, 66 to read, 14 detached, 200 fire-and-forget); 21.25 days, first cut 15 (12.5 to 15 under D7 (c)) |
