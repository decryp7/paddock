# Amendment to ADR 0076 (2026-11-09): a stop has a budget and never waits on a member inside an uncancellable external call

- Status: Proposed (2026-11-09). An amendment to ADR 0076 (accepted 2026-11-09), which is not on `origin/main` yet: it
  lives on `origin/docs/adr-0076-owned-background-work` (`a1fe4599c`). This file is merged into the ADR's text when that
  branch lands.
- Related: ER-21 / rule 40, ER-27, ER-28, ADR 0076 §2 (`TaskGroup`), §2a (latches, `Overran`, the reaper), §6
  (`Detached::UncancellableCall`, cap 8), D4 (bounds), ADR 0077 (a test agent no longer reaches the helper at all).

## Trigger

ADR 0076 bounds each group's stop, but not the **sum** of the stops a process makes before an outside deadline, and it
waits up to the bound for a member that cannot see its token because it is inside a call that cannot be interrupted.
Dyno's agent did exactly that and was killed by its own signal watch.

## Evidence

`c03fb61be` on `origin/fix/dyno-agent-term-race` (CI job 33005, run 7810, macOS; cause C2 in its message):
`Running::stop` joined the `dyno-climate` worker while it was inside a helper counters read (`powermetrics`, about 2 s per
id). Under load the joins passed `SIGNAL_STOP_GRACE` (10 s) and the signal watch ended the process with exit 143 ("the
stop did not finish in time"). Measured: 20 of 30 and 6 of 10 runs exited 143 before; 0 of 30 with the worker off; 3 of
10 with it back on. The fix moves helper readers to a `readers` list that the stop does not join (it logs "Agent left a
helper read in progress to end by itself" with the thread name), records what the stop is waiting on
(`stop_waiting_on()`, read by the signal watch when it ends the process), and logs the slowest thread. A second log line
in the same stress runs: "waiting on dyno-wakes" (a helper call during the stop, cause C3, ADR 0077).

## Change

1. **A process stop budget.** A composition root (ADR 0037) declares its process's stop budget (Dyno's agent: the TERM
   grace); the sum of the bounds of the groups it stops in sequence, plus the reaper's settle, must fit inside it with a
   declared margin. `TaskGroup::stop` takes the remaining budget (`Deadline`), not only its own bound, so a late group gets
   what is left, never more.
2. **External calls are declared.** `TaskGroup::external(role, what, f)` (or a guard `group.in_external(what)`) marks a
   member as inside a call it cannot cancel (helper, OS counter, plugin). `stop` does not wait for a marked member at all:
   it is `Abandoned { what }` at once, its handle goes to the reaper as a `Detached::UncancellableCall { what }` (counted
   in the cap of 8), and the member's result is discarded: it writes nothing after its group stopped (the token is checked
   before any write, as Dyno's reader already does).
3. **Join with a deadline, abandon after it.** Unchanged from §2a for unmarked members (latch, then join; `Overran` to the
   reaper at the deadline); this amendment adds the `Abandoned` outcome and requires that no stop path calls
   `JoinHandle::join` without a set latch.
4. **Logs (ER-27).** While a stop runs, `TaskGroup` keeps "waiting on <owner>/<role>" readable from any thread (what
   `stop_waiting_on()` does for Dyno), so a signal watch or a watchdog that gives up names it; the stop report lists each
   member's outcome and duration and each abandoned external call with `what`; a member that enters an external call
   during a stop is logged by name.

## Check

- **C42** (ADR 0076 §4) gains: a call into a registered external-call API (Dyno's helper client, `paddock-service`'s
  privileged calls, counters readers; the list lives with ADR 0077's register) from a `TaskGroup` member outside
  `external(..)` is an error; and `JoinHandle::join` outside `paddock_jobs::tasks` in shipped code is an error (the
  ratchet lists today's).
- **Model tests** (on a `FakeClock`, WP-1 of 0076): `a_stop_never_waits_for_a_member_in_an_external_call`,
  `stops_in_sequence_share_one_budget`, `an_abandoned_member_writes_nothing_after_the_stop`.
- **Positive control:** `git show c03fb61be^:apps/dyno/crates/dyno-agent/src/lib.rs` must be flagged at the climate
  worker's join; the fixed file must not. Dyno's failing-first test `helper_seam
  a_stop_does_not_wait_for_a_counters_read_in_progress` moves onto `TaskGroup` with WP-5.
