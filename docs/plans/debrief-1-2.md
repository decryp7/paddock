## 2. Waves of work packages

Conventions for every package:

- One agent, own worktree of `paddock` (sparse: `crates ui scripts docs eslint conformance apps/debrief`), own
  `CARGO_TARGET_DIR`, own e2e port, `CARGO_BUILD_JOBS=2`, heavy jobs through the machine's slots (rule 41).
- Branch `debrief-1-2/<id>` from the integration branch `integrate/debrief-1-2` (made by 0.1 from the combined state of
  section 0); the coordinator merges each package when its gates pass. Tests: what `scripts/affected.mjs` selects plus
  the touched specs, Playwright in Chromium only (rule 3). Lint and type-check the touched files. `CHANGELOG.md`
  (Unreleased) for shared changes, `apps/debrief/CHANGELOG.md` for Debrief's.
- Shared integration points (`apps/debrief/app/src/app/app.config.ts`, `app/src-tauri/src/lib.rs` command table,
  `api.types.ts`, `crates/Cargo.toml`, `apps/debrief/Cargo.toml`) take **one declared line or block per package**;
  anything more is done by the package that owns the file in that wave.
- A bug fix starts from its failing test (rule 5). Wave 0 writes those tests as `test.fail` / `#[ignore = "<reason>"]`
  so the integration branch stays green; the package that fixes the bug removes the marker as its first commit.
- Every shared package carries the full tests of its behaviour (unit, robustness, property, real OS where it matters)
  and is adopted by `shell-demo` or `workbench-demo` in the same change. A Debrief package that adopts a shared part
  deletes its own copy and the tests that duplicated it, and records test count and time before and after (rule 43).
- Within a wave the owned files do not overlap. A package starts when its dependencies are merged and a slot is free;
  waves are the order, not a barrier (slot filling, section 5).

Roles: **implementer** = Sonnet, mechanical, precise brief; **designer**, **reviewer**, **researcher** = Opus;
**scout** = Haiku (CI watching, logs, inventories). Every package is reviewed by a reviewer that did not write it before
merge (scout watches its CI run). Effort is agent-days of focused work including tests (±50 %).
