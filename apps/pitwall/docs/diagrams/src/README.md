# Diagram sources

The `.drawio` files and `pitwall-overview.svg` one folder up are generated by these scripts from the Paddock diagram kit
(`paddock/diagrams/tools`, expected as a sibling checkout next to `pitwall`). The `.drawio` files stay editable in draw.io;
re-running a script overwrites its diagrams, so make lasting changes here.

```sh
node docs/diagrams/src/c4.mjs         # one family: c4 (context, containers), c43 (components), cls, deploy, seq, state, uc, overview
scripts/export-diagrams.sh            # then export SVG (and the git-ignored 2x PNGs); DRAWIO=/path/to/draw.io if it is not on PATH
```

`common.mjs` holds the Pitwall theme and the output date; `uc-lib.mjs` draws use-case diagrams; `overview.mjs` writes the
hand-built, theme-aware overview. Generation is deterministic: the same scripts produce the same files.
