# Diagram style

Pitwall's diagrams follow the suite spec in the Paddock repo: [`diagrams/STYLE.md`](https://dev.decryptology.net/decryp7/paddock/src/branch/main/diagrams/STYLE.md)
(roles, type, grid, connectors, size limits, export). Start new diagrams from Paddock's templates and shape library
([`diagrams/README.md`](https://dev.decryptology.net/decryp7/paddock/src/branch/main/diagrams/README.md)); `scripts/export-diagrams.sh` is Paddock's,
copied unchanged. The diagrams here are written by the scripts in [`src`](src/README.md), not drawn by hand.

## Pitwall's colours

Light / dark, stroke on fill (from `tools/themes.mjs` in Paddock).

| Role | Colours | Use here |
|---|---|---|
| Own container (accent, violet) | #6D3FD6 on #F0ECFB / #A58BFA on #2C2A3F | the server, shell, tray, CLI, server modules, states, use cases, classes |
| Pure core | #007A5E on #E6F2EF / #2EC4A0 on #193330 | `pitwall-core` and its components |
| UI | #0072B2 on #E6F1F7 / #56B4E9 on #1F303C | the Angular UI |
| Process / OS / data | #565E6B on #F0F2F5 / #A0A7B2 on #1B1E23 | engine processes, OS service manager, credential store, data folder, people, in-process modules in sequences |
| External | #6B7380 dashed on #F4F5F7 / #7F8794 on #17191E | Hugging Face, GitHub releases, other computers |

Rules that matter most here:

- Amber is never a role colour; engine processes are neutral.
- Planned work is the role's colour, dashed on white, **with a "planned" tag**; it is never a different box style. Planned today:
  LAN sharing with TLS, MLX / vLLM / whisper.cpp engines, the response cache wiring (and, not drawn yet, RAG and MCP).
- Pitwall is strictly local: no cloud, no telemetry. The only arrows that leave the machine are downloads the user asked for
  (Hugging Face, GitHub releases).
- A diagram has at most 12 edges and fits 1600 × 1200 (sequences 1800 tall), so large ones are split: core in four, server
  in two, UI in two, deployment per OS, use cases in three, classes in three, the chat request in two.
- Sequences carry activation bars; labels on neighbouring participants are kept short enough to sit beside the line.
- One overview, `pitwall-overview.svg` (light and dark in one file), generated by `src/overview.mjs`.

The footer reads "Pitwall · updated YYYY-MM-DD". Update the date in `src/common.mjs` when a diagram changes. The 2x PNGs under
`docs/diagrams/png/` are for local review and are not committed.
