# Diagram sources

The `.drawio` files and `pitcrew-overview.svg` one folder up are generated by these scripts from the Paddock diagram kit
(`paddock/diagrams/tools`, expected as a sibling checkout next to `pitcrew`). The `.drawio` files stay editable in draw.io;
re-running a script overwrites its diagram.

```sh
node docs/diagrams/src/state.mjs      # one diagram family (c4, c43, cls, deploy, seq, state, uc-run, overview)
scripts/export-diagrams.sh            # then export SVG (and the git-ignored 2x PNGs)
```
