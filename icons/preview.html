App icon family

The seven apps and Paddock as isometric motorsport objects (STYLE.md): one saturated hue per app on the shared enamel tile, one rendered object per app in true 30 degree isometric under one key light from the top left, one accent from the app's own hue. Small sizes are hand-drawn: 2:1 pixel isometric at 32 and 24, a flat symbol at 16 and in the tray. The flat set this replaced is in archive/2026-10-flat/.

Tray and menu-bar icons

Each status has four tiles: the macOS template on a light and a dark menu bar, then the Windows icon on a light and a dark taskbar. Badges are whole pixels: Debrief, Pitwall, Sighter and Pitcrew cut a gap into the glyph in the bottom-right corner, Spotter and Dyno set a 3 x 3 square in a corner the glyph leaves free; Pitwall idle dims the whole glyph. On Windows they are coloured, and each status also has its own shape (dot, ring, triangle, cross), so colour is never the only cue.

Palette and colour-vision check

One hue per app, chosen by searching OKLCH space for the set with the largest minimum OKLab distance under simulated protanopia, deuteranopia and tritanopia (Machado 2009, full severity). Minimum ΔE (OKLab ×100): normal 17.7, protan 11.6, deutan 13.6, tritan 10.7. The glyphs also differ in silhouette, so hue is never the only cue.
