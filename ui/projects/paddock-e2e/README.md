# @decryp7/paddock-e2e

Playwright helpers and page objects for apps on the Paddock app shell (ADR 0012 §7). A plain Node package (ES modules
with type declarations), versioned with `@decryp7/paddock-ui`. Scaffold: the helpers arrive with plan S16
(`docs/plans/workbench.md`); until then the publish job holds it back.

Build: `npm run build:e2e` in `ui/` (writes `ui/dist/paddock-e2e`).
